`main.ts` writes one funny sign line (max 120 characters) to `/output/entry.txt`:

> The ghost in Rack 4 has root access. Knock twice, say please, and never unplug it.

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/haunted-sign-out node main.ts
```
